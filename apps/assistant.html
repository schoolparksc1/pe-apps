수행평가

나이스 업로드 파일

    명단 넣기

    출석부는 수업반별로 수행평가를 만들고 소속반·번호·이름을 넣습니다. 같은 수업반을 다시 넣으면 입력한 기록은 그대로 남습니다. 학년 전체 명렬표(학년·반·번호·성명·성별)를 넣으면 반·번호·이름이 모두 맞는 학생에게 성별을 채우고, 이후에 넣는 출석부에도 자동으로 채웁니다.

    파일 없이 직접 붙여넣기

    엑셀에서 소속반·번호·이름 세 열(또는 번호·이름 두 열)을 복사해 붙여넣으세요. 지금 수업반의 명단과 기록은 새 명단으로 바뀝니다.

    성별 입력

    학년 전체 명렬표(학년·반·번호·성명·성별) 엑셀을 화면에 끌어다 놓으면 반·번호·이름이 맞는 학생의 성별이 한 번에 채워집니다.

    엑셀에서 성별 열 붙여넣기

    명단과 같은 순서로 성별 한 열(남/여, M/F, 1/2 중 하나)을 붙여넣으세요. 1은 남, 2는 여로 봅니다.

    복사할 내용

    자동 복사가 막혀 있습니다. 아래 내용이 선택된 상태이니 Ctrl+C(⌘C)로 복사하세요.

    예시 명단입니다. 실제 반 명단은 ‘명단 넣기’에 출석부 파일을 끌어다 놓으세요.
    수업반은 이 수행평가의 반(출석부 제목), 연번은 출석부 순서, 소속반은 학생이 실제 속한 반입니다(나이스 파일의 ‘반’ 열). 상태 정상: 기록으로 환산 기본: 참여했으나 결과물 미제출·장기 질병 결시 미인정: 장기 미인정 결시(기본점수 −1) 여러 번 평가한 기록 중 가장 높은 기록이 반영됩니다. 엑셀 한 열을 칸에 붙여넣으면 아래로 채워집니다.
    왔으면 빈칸, 안 왔으면 칸을 눌러 / 표시합니다. 다시 누르면 지워집니다.수업 요일이면 오늘 날짜가 빨간 글자로 나타나고, 눌러야 출석 날짜로 등록됩니다(누르지 않으면 등록되지 않음). 수업 요일이 아닌 반은 비어 있는 날짜 칸을 누르면 오늘 날짜로 등록됩니다. 날짜를 지우려면 잠긴 날짜를 눌러 ‘이 날짜 지우기’를 두 번 누르세요. 입력 후 날짜를 한 번 누르면 그 날짜가 잠기고, 잠긴 날짜를 다시 누르면 잠금을 풀거나 ‘여기까지 나이스 입력 완료’로 표시할 수 있습니다(초록 ✓, 굵은 선까지 입력함).
    나이스 PAPS 입력 양식(학년 파일)을 넣으면 내 수업 학생 기록만 빈 칸에 채웁니다. 다른 학생 기록과 신장·체중은 저장하지 않습니다.내보내기는 그때 가진 최신 PAPS 파일에 내 학생 칸만 채워 같은 양식으로 내려받습니다.

    영역을 고치거나 추가하면 모든 반 수행평가에 바로 반영됩니다. 기록 환산형은 구간표로, 등급 선택형은 등급별 점수로 계산합니다.

    만든 이 · 다정고 박성찬

    체육 수업 도구예요. 출석부 파일로 반을 만들고 수행평가 기록·점수 환산, 출석 체크, 학생 점수 확인, 관찰 메모와 세특 쓰기, PAPS, 나이스 업로드 양식까지 한곳에서 합니다.

    모든 기록은 이 기기(브라우저)에만 저장되고 어디로도 보내지지 않아요. 나이스 시간표를 연결하면 이 기기에서 나이스 포털로 시간표만 받아 옵니다. 자유롭게 쓰고, 자기 수업에 맞게 고쳐 쓰셔도 됩니다.
