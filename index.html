체육 앱 서랍

체육 선생님이 수업과 업무에 직접 쓰려고 만든 도구들이에요. 설치나 로그인 없이 바로 열어 쓰고, 마음에 들면 HTML 파일로 내려받아 보관하거나 자기 수업에 맞게 고쳐 쓰세요.

i
모든 기록은 지금 쓰는 기기(브라우저)에만 저장돼요. 학생 명단이나 점수가 인터넷 어디로도 보내지지 않아요.
  • 다른 기기에서 열면 기록이 보이지 않아요. 옮길 때는 각 앱의 백업 파일 내려받기 → 불러오기를 쓰세요.
  • 재부팅하면 초기화되는 교실 PC, 브라우저 기록 삭제, 시크릿 창에서는 기록이 사라져요. 수업이 끝날 때마다 백업해 두세요.
  • 처음 써 볼 때는 앱 안의 예시 반 만들기로 둘러보세요.
